# polarbeaver-cast

The static Google Cast receiver for polarBEAVER.TV's LED board, published with GitHub Pages:

https://gratefulnuckle.github.io/polarbeaver-cast/receiver/

It's plain HTML, JS and CSS with Google's Cast receiver SDK. It makes no requests of its own: the polarBEAVER.TV app (in Chrome or Edge) sends the board's data over the Cast connection.

This repository only holds the built files. They're generated and published from the app's source, so please don't edit them here.
